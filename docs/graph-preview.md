## 已修复的 Bug

### Bug 1: Canvas 容器高度为 0
**问题**: 模态框使用 `max-h-[90vh]` 导致高度由内容决定，Canvas 容器实际高度为 0  
**修复**: 改为 `h-[90vh]` 固定高度为视口 90%

### Bug 2: 鼠标坐标计算错误
**问题**: `getMousePos()` 引用未定义的 `w` 和 `h` 变量  
**修复**: 使用 `canvas.width / devicePixelRatio` 计算实际宽高
